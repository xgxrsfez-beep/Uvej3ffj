# 🚗 د. درايفينغ أونلاين — خريطة اللعبة المشتركة

سيرفر للمود مينيو. كل اللاعبين يلتقون على خريطة اللعبة (نمط Video Game Maps
عبر Leaflet من github.com/topics/maps). الجميع يبدأ من ساحة الالتقاء
في منتصف الخريطة، يتحركون معاً ويتحدثون في دردشة عامة.

## 🗺️ من أين تحصل على صورة الخريطة؟
### الطريقة 1 — خريطة د. درايفينغ الحقيقية (الأفضل):
1. حمّل APK اللعبة
2. فك تجميعها: apktool d drdriving.apk
3. ابحث في assets/ أو res/ عن صور PNG للخريطة
4. اختر أفضل صورة → سمّها game-map.png → ضعها في public/map/

### الطريقة 2 — أي خريطة لعبة من الإنترنت:
- أي صورة خريطة علوية (top-down) واضحة — سمّها game-map.png وضعها في public/map/

## ☁️ النشر على Render
1. ارفع الملفات إلى GitHub (بما فيها public/map/game-map.png)
2. render.com → New + → Web Service → اربط المستودع
3. Create Web Service → انتظر 2-3 دقائق
4. الرابط الناتج يوضع في المود مينيو (OnlineActivity.kt)

## ⚠️ ملاحظة
الخطة المجانية تنام بعد ~15 دقيقة بلا زوار.
استخدم UptimeRobot مجاناً لفحص /health كل 5 دقائق لتبقيه مستيقظاً.
